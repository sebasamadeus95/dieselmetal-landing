# Diesel Metal — Landing page

## Publicación en GitHub Pages
1. Crea un repositorio público en GitHub, por ejemplo `dieselmetal-landing`.
2. Descomprime este ZIP y sube `index.html` y la carpeta `assets` a la raíz del repositorio.
3. En GitHub abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona `main` y `/ (root)`, guarda y espera a que GitHub Pages publique la web.
